# Underwater ROV Project

## Overview
This project is an underwater ROV using Raspberry Pi.

## Features
- Ethernet communication
- SSH remote access
- Dual BNO055 orientation sensors
- CSV telemetry logging
- 6 thruster control system
- Stabilization system
- Future camera integration

## Hardware
- Raspberry Pi
- BNO055 IMU
- ESCs
- Thrusters
- Ethernet tether

## Current Progress
- Raspberry Pi setup completed
- SSH enabled
- I2C enabled
- Ethernet communication working
- BNO055 integration started
